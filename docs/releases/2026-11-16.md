## What Changed and Why

Citation decisions now separate existence, retraction, and claim support.
Unavailable checks remain unknown; valid metadata without an abstract does not
certify a finding. Answer checking evaluates each claim/PMID pair independently
and retains source evidence. Optional NLI uses entailment/contradiction/neutral
predictions, not topical similarity alone. Its threshold requires independent EEG
calibration before clinical reliance.

BM25 and dense retrieval use the same inclusion filters before fusion. The
reranking pool is separate from the final cutoff, so a candidate below that cutoff
can be promoted. Original RRF and reranker scores remain distinguishable.
Blocking work moves off the event loop, with bounded model concurrency. NCBI
requests share pacing within an event loop/credential, metadata requests batch up
to 200 unique PMIDs, and HTTP connections are reused. Multiple processes or hosts
still need externally coordinated IP-level rate limits.

Vector collections record model/revision/dimension/pooling/normalization identity;
unproven or mismatched indexes fail compatibility checks unless explicitly using
the legacy override. Stable document IDs protect incremental uploads. Opt-in
Qdrant-native BM25/dense fusion reduces separate snapshot management. Compressed
uploads require durable external float32 originals; no production corpus was
switched automatically.

rtt indexes files, imports, classes, and signatures in
[.rtt/context.txt](../../.rtt/context.txt). Agents search it to choose a source
file, then read source and nearby tests. The structural artifact is generated,
not edited manually. It is not loaded by EEG-RAG at runtime. Run `rtt update`
after relevant changes and `rtt compare` for current token estimates.

## Researcher Installation

```sh
python scripts/install_researcher.py
python scripts/install_researcher.py --launch
```

The installer chooses CPU-first packages, creates an external environment, checks
installed versions, and preserves existing configuration. It avoids administrator
access, Docker, activation commands, and automatic 7B model downloads. uv is used
when already installed; otherwise it uses Python/pip. Downloading the repository
as a ZIP avoids requiring Git. Advanced pyBiblioNet/Infomap analysis is optional,
because a fresh install exposed a native-build dependency that is unsuitable for
the default researcher workflow.

The browser can open before provider/model configuration. Generated answers still
need a local or cloud LLM provider; dense search needs an indexed Qdrant service.
Keep API keys local and independently verify sources before clinical use.

## Compatibility and Validation

The fresh researcher installation and actual Streamlit main screen were verified
under Python 3.12. Tests exercise failed checks, contradictory claims, filter
boundaries, candidate promotion, cancellation, metadata identity, compressed
archives, and snapshot restore. The benchmark command requires independently
labeled relevance data; fixture encoders do not establish semantic quality.

Torch is the tested default. ONNX options are not a recommended working exporter
stack: published Optimum ONNX dependencies conflict with Transformers 5.
OpenVINO and pyBiblioNet extras have conflicting upstream Requests requirements.
Neither conflict is bypassed with dependency overrides.

Remaining scientific gates: independently adjudicated EEG relevance/entailment
labels, NLI threshold calibration, production-size concurrent ingestion, and
model/backend comparisons on deployment hardware. Multi-vector pooling is a
future experiment, not an implemented corpus migration. Report latency targets
as targets until measured; generic upstream results are not EEG-RAG results.
